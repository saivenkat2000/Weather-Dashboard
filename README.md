# Weather Dashboard

## Overview

Weather Dashboard is a responsive web application built using HTML, CSS, and JavaScript that provides real-time weather information for cities around the world. The application integrates with the OpenWeatherMap API to retrieve live weather data and display it in an intuitive and user-friendly interface.

Users can search for any city to view current weather conditions, including temperature, humidity, wind speed, and weather descriptions. The dashboard dynamically updates weather images based on the current weather condition, enhancing the overall user experience.

## Features

- Real-time weather data retrieval using OpenWeatherMap API
- City-based weather search
- Display of temperature, humidity, and wind speed
- Dynamic weather condition images
- Error handling for invalid city names
- Responsive and user-friendly design
- Fast and lightweight implementation using Vanilla JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API
- Font Awesome Icons

## How It Works

1. User enters a city name in the search box.
2. JavaScript sends an API request to OpenWeatherMap.
3. Weather data is fetched asynchronously using Fetch API.
4. The dashboard displays:
   - Temperature
   - Weather Description
   - Humidity
   - Wind Speed
5. Weather images change dynamically according to weather conditions.
